# Alternance

Moteur de recherche et tableau de bord pour piloter une recherche d'alternance.

## Fonctionnalités
- Recherche et filtres par métier, ville, contrat, niveau et télétravail
- Matching simulé avec score de pertinence
- Favoris persistants dans le navigateur
- Pipeline de candidatures
- Profil candidat personnalisable
- Mode sombre
- Export JSON des données
- Interface responsive

## Lancer
Le projet est une application web statique : ouvrir `index.html` suffit.

> Les offres présentes sont des données de démonstration. Une prochaine étape consiste à connecter des sources/API d'offres réelles et une authentification.
